# JVRecruit Product Roadmap

## Phase 1 — Foundation

- Dedicated GitHub repository
- Dedicated Supabase organization/project
- Environment separation
- Initial Postgres schema
- RLS
- Private résumé storage
- Admin authentication

## Phase 2 — Public experience

- JVRecruit landing
- Open Roles
- Confidential job detail pages
- Apply to a Role
- Join My Network
- Resume upload
- Candidate deduplication

## Phase 3 — Core ATS

Navigation:

`Dashboard · Jobs · Candidates`

Pipeline:

`Applied → Prescreen → Submitted → Client Sub → Interviewing → Offer → Placed`

Also searchable outside the main board:

- Rejected
- Withdrawn
- Archived

Core features:

- drag-and-drop pipeline
- candidate master profile
- candidate drawer
- application-specific notes
- candidate-wide notes
- activity history
- configurable interview stages per job
- manual Add Candidate

## Phase 4 — Search and reporting

- candidate search
- filters by stage, role, source, location, owner
- active role dashboard
- applicant / prescreen / submission / interview / offer / placement metrics
- pipeline aging
- source reporting

## Phase 5 — Recruiting workflow

- email/calendar integrations
- interview scheduling support
- outreach templates
- candidate reminders
- Chrome sourcing extension
- Add / Pass evaluation
- candidate history before adding

## Phase 6 — Advanced

Only if needed:

- AI search/matching
- semantic candidate search
- client portal
- organization/collaborator permissions
- multi-tenant model for use outside one recruiting operation
